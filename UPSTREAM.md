# Upstream provenance

This independent Windows product starts from the `windows/` directory of
[Karl-Dai/VeloxClip](https://github.com/Karl-Dai/VeloxClip), commit `6cd6096`.
The original Windows code was authored by the VeloxClip contributors.
As of ClipNest 0.2.3, all shipped branding assets have been replaced with
independently drawn ClipNest artwork (notes resting in a nest). No upstream
VeloxClip icon is used in the app or its distribution. Editable artwork is in
`design/clipnest.svg`; `build/Generate-BrandAssets.ps1` generates the icon sizes.
The upstream README declares MIT licensing; the imported snapshot did not contain
a standalone LICENSE file. This notice preserves attribution without inventing a
copyright notice or replacing upstream licensing terms.

The original Windows design documents are preserved in `docs/upstream/`.
New work lives in this repository, independently of the macOS project.
