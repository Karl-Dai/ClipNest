# 拾贴 ClipNest 0.4.1

- 修复长文本历史反复加载导致的内存增长，列表只读取摘要，正文按需读取，复制完整内容。
- 搜索改为后台执行并增加防抖；历史支持分批加载，不再只可浏览最近 500 条。
- 降低历史上限后立即清理超出的普通记录和图片，收藏继续保留。
- 大图预览限制解码尺寸和缓存容量，快速切换时不会被旧选择覆盖。
- 保留桌面 / 开始菜单快捷方式、独立数据目录和 GitHub 自动更新功能。

## 验证结果

- 120 项核心测试通过，Release 构建零警告、零错误。
- 4K、8K 与长图连续切换 240 次，另加 80 次重叠快速选择。
- 连续文本复制 100 次，全部捕获；65,579 字符正文复制完整。
- 连续运行 60.02 分钟、715 次循环与采样，零项失败；历史裁剪后保留全部收藏。

测试范围与原始数据见 [完整报告](https://github.com/Karl-Dai/ClipNest/blob/v0.4.1/docs/testing-0.4.1.md)。

## 下载与升级

Windows 11 22H2 或更高版本，x64。普通用户下载 `ClipNest-0.4.1-Setup-x64.exe`；便携版下载 `ClipNest-0.4.1-win-x64.zip`。升级前请先从托盘退出旧版。

此版本暂未进行代码签名，安装时可能显示“未知发布者”。可使用 `SHA256SUMS-0.4.1.txt` 核对下载文件。安装版可通过自动更新获取此版本；便携版需手动更新。
